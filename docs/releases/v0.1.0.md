# StatGuard Desktop v0.1.0

StatGuard Desktop v0.1.0 is the first public Windows desktop release of the StatGuard companion application.

It packages StatGuard v1.0.0 into a standalone Windows GUI.

## Highlights

- Double-click Windows application; no Python or separate StatGuard installation is required.
- StatGuard Core 1.0.0 with 11 rules (ML001–ML009 and ST001–ST002).
- Scan `.py` files, `.ipynb` notebooks, and directories.
- Project, custom TOML, and no-configuration modes with rule, exclusion, and fail-on controls.
- Finding filters, search, details, and drag-and-drop target selection.
- Export HTML, JSON schema 1.0, and SARIF 2.1.0 reports.
- Static analysis safety model: submitted Python and Notebook code are not executed, and Notebook outputs are not analyzed.

## Download

Recommended: [StatGuard-Desktop-0.1.0-windows-x64.zip](https://github.com/hyynb666/statguard-desktop/releases/download/v0.1.0/StatGuard-Desktop-0.1.0-windows-x64.zip). Extract the ZIP and double-click `StatGuardDesktop.exe`.

The standalone [StatGuardDesktop.exe](https://github.com/hyynb666/statguard-desktop/releases/download/v0.1.0/StatGuardDesktop.exe) is also provided. The ZIP includes `README.txt`, `LICENSE.txt`, and an internal checksum manifest. `SHA256SUMS.txt` alongside the release assets verifies both binary downloads.

Requirements: Windows 10/11, 64-bit x86_64/AMD64. No Python installation or separate StatGuard installation is needed.

The Windows executable is not code-signed. Windows SmartScreen may identify it as an unknown publisher. Do not disable Windows security features to run it.

## Limitations

- Windows x64 binary only; no ARM64, 32-bit, macOS, or Linux Desktop binaries.
- No installer, auto-update, scan cancellation, or source-editor integration.
- Static analysis only; supported patterns do not imply cross-file or cross-Notebook-cell inference.
- A clean scan does not prove statistical correctness.
